## Veylor

<a href="https://veylor.dev/">Veylor</a> is my growing ecosystem of tools and infrastructure built to solve the operational problems I encounter while building software products.
<a href="https://github.com/veylor-hq">Veylor Github Organisation</a>

The goal is to have a small, self-hosted platform where services can share common infrastructure instead of reinventing authentication, notifications, monitoring, and organisation management for every project.

### Ecosystem

* **SSO** — Central identity and authentication service for Veylor applications, providing a shared login and organisation/workspace model.
* **Relay** — Notification and communication infrastructure. Handles outgoing email and other delivery channels while keeping individual applications decoupled from providers.
* **Velo** — Lightweight feature/configuration infrastructure used across the ecosystem.
* **Overseer** — Central monitoring and operations platform. Keeps track of Veylor services, nodes, health, heartbeats, incidents and system status.
* **Warden** — Asset and workforce management platform for tracking equipment, staff, licences, assignments and operational information.

Veylor is designed around **small, focused services with shared infrastructure**, rather than building one huge monolithic platform. Each component has a specific responsibility while remaining usable independently.

Most of the systems are open-source and can be found inside of <a href="https://github.com/veylor-hq">Veylor Github Organisation</a>
